# 🎓 Enrollment System (Java)

A simple Enrollment Management System developed in Java using Swing (JOptionPane) as part of my academic projects. The application simulates the enrollment process of a college institution, allowing students to register, select courses, choose sections, view subjects and units, apply scholarship discounts, and complete tuition payment transactions.

Features
Student registration and information management
Password creation and verification
Semester selection
Multiple course offerings:
BS Computer Science (BSCS)
BS Information Technology (BSIT)
BS Business Management (BSBM)
BS Hotel and Restaurant Management (BSHRM)
Associate in Computer Technology (ACT)
Hospitality and Restaurant Services (HRS)
Section and curriculum selection
Subject and unit computation
Scholarship discount processing (40% discount)
Tuition fee computation
Payment and change calculation
Enrollment summary generation
Technologies Used
Java
Swing (JOptionPane)
Object-Oriented Programming Concepts
Purpose

This project was created as a learning exercise to practice:

Java programming fundamentals
User input validation
Conditional statements and loops
Data processing and calculations
Basic enrollment system workflow simulation

⚠️ This project was developed during my college years and is preserved as part of my learning journey in software development. Newer projects will showcase modern technologies such as C#, ASP.NET Core, SQL Server, REST APIs, and full-stack web development.
